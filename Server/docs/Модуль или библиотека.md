# Модуль
## Структура

### Я Хочу пользоваться преимуществом ООП, как мне это сделать?
Для начала, тебе трубется иницилизировать Свои классы или main класс.
Делать это лучше всего в функции `M.load()`, она будет вызванна при иморте модуля.
Советуется писать весь код модуля в одном файле, или использовать глобальные переменные.

### Я пишу процедурные программы, где находится вход в программу?
Можно написать функцию `main`, и после вызвать ёё в 0 позиции.(В не какой либо функции)
```lua

function main()
    print("Hello World!")
end
main()
```
Или вызвать функцию `main` в M.load()
```lua
function main()
    print("Hello World!")
end

function M.load()
    main()
end
```
#### В чём разница этих методов?
Метод `main()` будет вызван немедленно при инициализации файла загрузчиком. 

Минусы:
- Могут отсутствовать глобальные переменные
- Не все глобальные функции инициализированные

Плюсы:
- хз
- хз
---
Метод `M.load()` будет вызван при импорте модуля.
Плюсы:
- Все штатные функции инициализированы
- Все глобальные функции инициализированы

Минусы:
- хз
- хз
---
Методы не противорячат друг другу, и могу дополнять друг друга.
Можно вызывать функцию main, для инициализации переменной данными, а в M.load() уже пользоватся ими. 
Хотя и main и M.load() будут вызванны всего 1 раз.



```lua
local M = {}
M.info = "Name module"
M.ver = "текст" -- Данное поле еще не как не раелизованно, и пригодится в будущем
M.author = "Author"


-- если есть глобальные переменные которые вы хотите использовать такой кусок кода
abstract_peremen = abstract_peremen or {} -- Тем самым, вы обезопасите, себя если друг, переменная будет пустой.
-- Если команд есть.
M.command = {
    {category = "env",command = "set", help ="Установить время суток.",args="[08:00]",func ="ENVSETIME",roles = {"moderator","admin"}}
}
-- Если команд нет, лучше не использовать, что бы ускорить импорт, модуля.
M.command = nil

function M.load() -- Запускаетс когда используешь 'import' в main
    MP.RegisterEvent("onPlayerJoin", "onPlayerJoinENV")
    HeventTimer.addFunc(global_abstract_function, 1) -- Для таймера.
    
end
 
function M.unload() -- Запускаетс когда сервер завершает работу штатным способом (Временно не работает)
end

return M
```
