# BeamMP RP Plugin

Серверный и клиентский мод для ролевого сервера на [BeamMP](https://beammp.com) в BeamNG.drive: экономика, работы, машины, роли и интерфейс игрока.

## Возможности

- Экономика, гараж и тест-драйв
- Работы: доставка, такси, автобусы, грузовики и служебный транспорт
- Достижения и учёт времени в игре
- Ролевые команды, баны, права и мут
- Геоданные и синхронизация погоды
- Клиентский интерфейс и ограничения сессии

## Структура

```text
Client/     клиентский мод BeamNG
Server/     логика сервера BeamMP
SteamUI/    раскладка интерфейса
OldServer/  старые черновики и примеры
python/     вспомогательные скрипты
```

Заметки по модулям лежат в `Server/docs`.

## Ветки

| Ветка | Назначение |
| --- | --- |
| `main` | стабильная линия |
| `dev` | текущая разработка |

## Установка

### Сервер

Скопируйте каталог `Server` в моды BeamMP-сервера и перезапустите сервер.

### Клиент

Поставьте каталог `Client` как клиентский мод. Текст приветствия, ограничения и синхронизация времени задаются в `Client/settings/config.lua`.

## Деплой

Файлы в `.github/workflows` выкладывают серверную часть по SSH. Адрес, пользователь и пароль в репозитории не хранятся: их нужно задать секретами `FTP_HOST`, `FTP_USERNAME` и `FTP_PASSWORD`.
